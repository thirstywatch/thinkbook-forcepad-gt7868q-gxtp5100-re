# 【交付二】按触控板**硬件逻辑链**的成果总表（2026-10-14 统合）

> 读法：从**手指**开始，沿**信号/命令实际流经的硬件与接口**往下走；每一环给出**触发/输入 → 端口/地址/命令 → 去向**，并标注证据与缺口。
> 与《全链路闭环总纲》（L1–L10 分层）互补：总纲按**层次**，本表按**信号流**。

## §4 S3 触控 IC **GT7868Q / GXTP5100**（主控）

| 触发/操作 | 端口/地址/命令 | 结果/去向 | 证据 | 等级 |
|---|---|---|---|---|
| 主机读 IC 内存 | `0E 20 00 00 05 01 <addr16BE> <size16BE>`（**16 位地址**，>0xFFFF 静默截断） | RID 14 INPUT（≤60 B/帧） | §19.79 | ★★★★★ |
| 主机写 IC 内存 | `0E 20 00 00 <len+5> 00 <addr16BE> <len16BE> <data>` | 同上 | `tools/hid/gxmem.py` | ★★★★★ |
| **64 KB 分 bank** | `HW_REG_BANK_SELECT = 0x2048`（实测 `01`） | 同一地址在不同 bank 是不同对象 | §19.79 | ★★★★ |
| 命令寄存器 | **`0x4160`**（`0xFF`=空闲；卡住会阻塞会话） | 会话控制 | B41/B76/纪律 186 | ★★★★★ |
| **cfg 配置窗口** | **`0x96F8`**（1084 B = 头 5 B + **27 袋**，袋尾 YS 校验） | 会话期有效、`0x7D` 后仍驻留到断电 | §19.42/§19.51 + **B72** | ★★★★★ |
| 状态字 | `0x5095`（`0xDD`=bootloader）· **`0x5096`**（flash 结果；正常 `75` 字头，退化 ∈`{AA,BB}`）· `0x5000`–`0x50FF` **不可靠窗口** | 健康/退化判据 | `RECOVERY.md` + **B74** | ★★★★ |
| 版本/身份块 | **`0x4014` + 135 B**（自描述长度 `00 87` + **两层 YS** + `YELSTO`/`7869`/`fw_version`/块尾 `{addr,len}` 表） | IC 自述 | §19.69/A#11 | ★★★★★ |
| 数据表基址 | **A1/A2/A3 = `0x86B8`/`0x8E38`/`0x8078`**；`0x8000` 段 = **固件数据表区** | 与 DLL 五分支表互证 | §19.71/A#36/A#43 | ★★★★ |
| 校准/曲线块 | **`0x4280` 起 1216 B**（两段式：704 B 稠密 + 512 B 平滑） | 非密钥 | A#44 + **B54/B55** | ★★★★ |
| 基线 vs 当前 | **`0x7F10`（静态·基线）** vs **`0x7F88`（活体·当前）**，16 项**逐项差 ≤2.43%** | 同一量的基线/当前 | **B62/§19.80** | ★★★★★ |
| 描述符副本 | IC 内存里有一份 HID 描述符（**会漂移**） | 能力判定必须以**设备原件**为准 | **B63/纪律 175** | ★★★★ |

## §9 S8 维护/更新链（读 → 改 → 写 → 恢复）

| 环节 | 端口/命令 | 事实/判据 | 证据 | 等级 |
|---|---|---|---|---|
| **cfg 会话** | 轮询 `0xFF` → 发 **`0x80`** → 轮询 **`0x82`** → 写 cfg → 发 **`0x83`** → 读 3 B → 发 **`0x7D`** | 写 `0x96F8`；**改动驻留到断电**（`0x7D` 不丢弃） | 官方 `gtx2_update.cpp` + **B72** | ★★★★★ |

| flash 布局 | 13 条子固件；cfg 子镜像 @**`0x1E000`**；**空隙 `0x18000–0x1DFFF`（含 `0x19000`）** | 容器解出 | §19.76/B58 | ★★★★★ |

| host cfg 落盘面 | 官方三套更新器的"落盘套路"里有一条**从未试过**的提交命令 | B19 | ★★★★ |

## §11 缺口（按硬件逻辑链排列）

| # | 缺口 | 卡在哪一环 | 最便宜的补法 |
|---|---|---|---|
| G1 | IC **可执行代码**（触发判据所在） | S7 | 无（工厂固件不可得/不可读）⇒ 只能改从行为侧逼近 |
| G2 | cfg **哪个袋/字段管触觉** | S3/S7 | **机械敲击器**解决 J1 功效后再扫；或先做 `bag 2` 语义校验圈定（判据=结果码） |
| G3 | flash 侧 cfg 的**编码/位置** | S8 | 无读回 ⇒ 只能间接 |
| G4 | AW86927 主机可达性 | S2 | 已结案（不可达） |
| G5 | TF100A 的**触发输入** | S1 | **SWD**（需采购+拆机） |
| G6 | `TRIG1/2/3` 是接 GND 还是有线驱动 | S2 | 拆底盖 + 万用表 |
| G8 | **触觉客观判据的功效**（J1 方差过大） | S7 | **机械激励** 或每袋 ≥10 窗重复 |
| G9 | `0x4160` 被锁时的**解锁** | S3 | 手段 2c（UAC）/ 重启 |
