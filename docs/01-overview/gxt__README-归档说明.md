## ★ 读归档文档时的四条护栏

### 护栏 1：命令有**四张表**，别混

| # | 名称 | 器件 | 入口 | 条数 |
|---|---|---|---|---|
| ① | **TF100A 内部分派器** | TF100A | `0x0800E1C0` | **39**（`0x80`×1 + `0xA0`×16 + `0xA1`×22） |
| ② | GT7868Q 内部分派器 | GT7868Q | `0x22C7C` | **16**（`0x0100`–`0x3500`） |
| ③ | GT7868Q 官方命令集 | GT7868Q | `CMD_ADDR 0x4160` | 约 10 |
| ④ | GT7868Q 主机报文 | GT7868Q | `0x1ACEC` | 6 种类型（`5A A5` + CRC-8 poly `0xA1`） |

★ **① 与 ② 的命令号完全一致** ⇒ **那 16 条属 TF100A，GT7868Q 侧只是中继副本。**
归档文档里的 "GT7868Q 有 16 条命令" 都应读作 "**TF100A 的 16 条命令**"。

### 护栏 2：红线是**四条**，不是三条

```
00 10  switch to patch   ← 绝不碰
00 11  start update      ← 绝不碰
0E 12  load flash        ← ★ 真正写 flash，绝不碰
0E 13  restart           ← 绝不碰
```
（归档的 `ROUND47-59` 只写了前三条，且未分清 `0E 12`（写）与 `0E 13`（重启）。）

### 护栏 3：写入窗口是 `0x08019000..0x0801FFFF`

**不是** `0x19000..0x26000`（那是把**偏移上限**当成了**绝对地址上限**）。

### 护栏 4："高熵区"不是密文，也不需要解密

- `追加三十七` §23 三重定量结案：**不是密文**，是结构化数据
- `ROUND60` §3.1：官方工具**全程不解密**，原样搬运
- `ROUND61-67`：胶囊由 Windows 交给 BIOS，**没有一方需要解密**

⚠️ 但 `ROUND24` 说「主程序从加密区启动」**也没错** —— 向量表表项确实指向高熵区。
**正确理解**：代码链接在高熵区；该区在主机侧不可解读，但**不是密码学密文**，且**设备侧不需要主机帮忙解密**。
