## 2. 现在该做的事：方案 A

### A1 · 软件（零成本、零风险，可立即开工）

- 复用已验证可用的管道：`gesture-lab/DumpPad.cs`（Raw Input，`RIDEV_INPUTSINK`，usage page `0x0D` / usage `0x05`）
- 手势：一指**右边缘**内滑 → 音量 ±；一指**左边缘**内滑 → 亮度 ±
- **震动节拍**：每滑过固定距离产出一个"震动事件"（先写日志 / 短促提示音 → 硬件就绪后改串口 `V 1`）
- 编译（零安装）：`C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`

**实测报表布局（别再重测）**

```
byte  0    = 报表 ID 0x04
byte  1    = 触点0：低4位=按键位 / 高4位=触点ID
byte  2-3  = 触点0 X（u16 LE，实测 1280–3071）
byte  4-5  = 触点0 Y（u16 LE，实测 0–2047）
byte  6-7  = 触点0 压力（u16 LE，点击≈141–149，用力可达 ~497）
byte  8    = 触点1 起始（每触点 7 字节，共 5 个触点 → 至 byte 35）
byte 36-37 = 扫描时间    byte 38 = 接触数    byte 39 bit0 = 按下状态
```
边缘区建议：右 X ≥ 2950、左 X ≤ 123（≈4%）

### A2 · 硬件（¥40–65，**需用户决定是否购买**）

- **ESP32-C3**（¥15–25）+ **DRV2605L** 触觉驱动模块（¥15–30，自带 LRA 波形库）+ 方形 LRA（¥5–10）
- 串口协议：一行一条 `V 1` = 震一下；强度/时长/波形可调
- **现成参考实现**：`github.com/barryblueice/ESP32-Haptic-Precision-TouchPad`（wiki 含硬件、波形、编译全套；注意他的方案是 **Surface + CS40L25**，硬件不同但思路可直接抄）

### 诚实预期管理（务必对用户讲清）

- **震动时机**：与华为同级 —— 完全由我们决定（原生只在点按时震）
- **震动质感**：打折扣 —— 外置 LRA 无法等效"贴在触控板玻璃下方的原装马达"

## 3. ⚠️ 红线（违反会打挂触控板，已实证两次）

1. **禁止对 `Col04` 做后台轮询**：`GetInputReport` 循环不得常驻；嗅探只能前台、≤30 秒、间隔 ≥200ms
2. **禁止枚举 / 批量试探厂商命令空间**：`0x0E`/`0x0F`/`0x99` 会**打断应答通道**并恶化成彻底失效
3. 厂商通道只允许**单发、已知安全**的命令（当前仅 **`0x20` 读**）；🔴 **红线是四条，不是“三连”**：`00 10` / `00 11` / **`0E 12`（★ 真正写 flash）** / **`0E 13`（重启）** 绝对不碰
4. 出现任何异常，**第一步是杀掉所有后台任务**
5. 触控板是本机**唯一指点设备**：任何可能让它停摆的操作，先备好不依赖它的退路
6. **打挂后的唯一恢复**：关机 → **拔充电器** → **长按电源键 20–30 秒** → 等 1 分钟 → 开机
   （**热重启 / `disable-enable` / `restart-device` / `scan-devices` 全部无效**；机底那个孔是 **Novo 按钮孔，只进菜单不断电**）

## 4. 别重走的路（全部已实测证伪，别浪费轮次）

| 路线 | 结论 | 一句话依据 |
|---|---|---|
| HID 主机触发 | ❌ 接口不存在 | `Col02 out=0`；page 0x0E 下只有 `Intensity`；微软规范要求 `Manual Trigger` OUTPUT 报表 |
| 厂商命令空间 | ⚠️ **边界已解出，但"主机能否到达"仍未证实** —— 见 `COL04-BOUNDARY.md`：**类 3 个 + `0xA0`×16 + `0xA1`×22，边界外 = 无害 no-op**。但**读侧实测够不到 TF100A 的 RAM**，"GT7868Q 会不会把 `A1` 转发给 TF100A"**完全未验证**（`PREFLIGHT-STATE.md` §7 的 H1，**唯一的门**）。~~无震动命令~~ **作废**；~~"已经可以验证了"~~ **降级为：可以在样机上打的那一发** |
| 改配置 / 改点击阈值 | ❌ 无效 | 写入被丢弃；阈值与波形都在 MCU 侧（编译期常量） |
| 内核 HID 过滤驱动 | ❌ 不值得 | 前提是"探测命令空间验证隐藏能力"，而该空间既不能探也无命令 |
| 改固件 | ❌ 单程门 | 波形/阈值在 **GT7868Q 加密固件**里；eFuse 验签 + 无自助刷回通道 |
| 解密加密载荷 | ❌ 实质不可破 | AES（16 字节块重复率 10.97%），无密钥线索；非任何标准压缩（gzip/zstd/lz4/bzip2/xz/zlib 全失败）|
| 找其它执行器 | ❌ 无 | 模组内只有一颗 LRA，驱动在 TF100A 里 |
| 抄 Surface/EC 方案 | ❌ 架构不同 | Surface 触控板挂在 **SSAM（=EC）** 后面，主机可达；本机触控板直连 **`PCI\VEN_8086&DEV_7E78`** Intel I2C 控制器，**不经过 EC**（实测设备树）|
