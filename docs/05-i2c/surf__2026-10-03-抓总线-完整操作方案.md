# 抓总线 —— 完整操作方案（抓什么 · 怎么接 · 抓完怎么搞）

> 日期：2026-10-03 · 接上一轮结论：**蓝莓的 167 块 = 固件里的写序列；我们那份等价物 = 上电时私有 I²C 上的写序列。**
> 本文回答「抓出来怎么搞」：**抓哪个信号、用什么设备、接在哪、抓到后怎么变成能用的东西。**
> 配套工具：`aw86927_bus_decode.py`（已通过 `--selftest` 自检）

## 〇、一句话

> **抓一次"开机后前 3 秒"的私有 I²C，跑一遍解码器，导出 `aw86927_replay.h`。**
> **那份头文件就是你自己的"167 块"—— 可以直接编进 MCU，让 LRA 响。**

## 一、抓哪条总线（不要抓错）

触控板模组里有**两条完全不同的 I²C**：

| | 主机总线 | ★ **私有总线（要抓这条）** |
|---|---|---|
| 谁跟谁 | Intel I²C0 ↔ GT7868Q | **GT7868Q ↔ TF100A(0x2C) ↔ AW86927(0x5A/0x5B)** |
| 走什么 | HID 报文（触摸坐标、按键） | **寄存器配置 + 波形下载** |
| 速率 | 400 kHz | 400 kHz（TF100A 侧已证） |
| 在 ACPI 里的名字 | `\_SB.PC00.I2C0.TPAD`（`_ADR=1`） | **没有对外名字** ⇒ 必须在模组 PCB 上找 |
| 抓它的价值 | 只能做"时间对齐"（点击↔写入） | ★ **波形数据只在这里出现** |

**⇒ 必须抓私有总线。** 主机总线上永远看不到波形。

## 二、第 0 步（零成本，先做这个，别急着买设备）

**拆机取出触控板后，用万用表通断档从 AW86927 的 SDA/SCL 引脚往外追。**

| 追到什么 | 含义 | 后续 |
|---|---|---|
| 追到**对外 FPC 触点**或那 7 个外露金属焊盘 | ✅ 不用板内焊接 ⇒ **风险大降** | 从触点引线即可 |
| 只能追到模组内两板之间的 8-pin FPC | ⚠️ 需要在模组板内焊（0402 级） | 风险中高，需熟练 |
| 追到的是**主机总线**（`I2C0.TPAD`） | 🔴 **§19.25.4「GT7868Q 是 AW86927 的 I²C 主机」这条淘汰法结论就要重写** | 先重审方案 |

> ★ **这一步本身就是项目悬了很久的硬件判据**（§19.25.6 的那条"唯一下一步"）。
> **它一次同时回答两件事：① AW86927 挂在哪条总线 ② 能不能免焊接引线。**

**同时顺手做的第二件（也是零成本）**：AW86927 的丝印是 `CA4F`，封装 `FCQFN 2×3-20L`。
在模组 PCB 上先**确认它的针位**（`HDP=pin7` / `HDN=pin5` / `RSTN=pin1`），后面要用到。

## 四、接线（5 根线，一次焊好两件事都做）

```
AW86927 (丝印 CA4F, FCQFN 2×3-20L)
   ├── SCL  ──┐
   ├── SDA  ──┤── 0.1mm 漆包线 ×3 ──→ 逻辑分析仪 CH0 / CH1 / GND
   ├── GND  ──┘
   ├── HDP (pin7) ─┐
   └── HDN (pin5) ─┴── 漆包线 ×2 ──→ 示波器 CH1 / CH2（差分看 200 Hz）
```

**要点**
1. **断电池再焊**，等 ≥5 分钟放电；**绝不带电焊接**。
2. 引线 **≤15 cm**；400 kHz 下长线会反射造成误码。
3. 焊点用 **UV 胶/热熔胶固定**，否则装机时必掉。
4. 引线从**底盖缝隙**或电池仓一侧引出，再合盖。
5. ★ **别短接 `HDP`/`HDN`**（那是驱动输出，短路会烧芯片）。

## 五、采集参数（这一步决定成败）

**核心难点：波形下载发生在【上电后很短时间内】，而整机开机要几十秒。**
所以不能盲目采，要**两轮采**：

| 轮 | 采样率 | 时长 | 触发 | 目的 |
|---|---|---|---|---|
| **第 1 轮（找窗口）** | 2 MS/s | **从按电源键前就开始，连续采 30 s** | 手动/自由运行 | 先找到"写波形发生在第几秒" |
| **第 2 轮（精采）** | 10–25 MS/s | 只覆盖那个窗口（±0.5 s） | **SCL 下降沿 + 预触发 50%** | 拿到无丢包的完整数据 |

**采样率下限推导**：I²C 400 kHz，每 bit 2 边沿 ⇒ 至少 800k 事件/s ⇒ **≥ 8 MS/s 才不丢边沿**，取 10–25 MS/s 稳妥。

> ★ **更聪明的触发源**：如果 AW86927 的 boost（`VBAT_CTRL`/`BST_VOUT`）有可测的 VOUT 上升，
> 用它当"上电"标记做触发，比靠 SCL 更准 —— **波形下载一定在 boost 起来之后**。

## 六、抓到之后：跑工具 → 三个判据（第一分钟就能出结论）

```bash
PY="<HOME>/.workbuddy/binaries/python/versions/3.13.12/python.exe"
cd "<WORKSPACE>"

# ① 先看工具读成了什么（格式不对时先跑这个）
$PY aw86927_bus_decode.py --in <你的导出>.csv --sniff

# ② 正式分析 + 导出可重放表
$PY aw86927_bus_decode.py --in <你的导出>.csv --outdir out
```

**输出解读表（照这个读，不要自由发挥）**

| 观察 | 结论 | 下一步 |
|---|---|---|
| **完全没有 `0x5A` / `0x5B`** | ★ **触觉链路当前未启用** | **方案空间重置**：AW86927 的 I²C/TRIG 是空闲资源，随便用 ⇒ 难度大降 |
| 有 `0x5A` 短写、**无大块写** | 初始化了但没下载波形 ⇒ 走 **RTP（芯片内固定波形）** | **不需要波形表**；改为研究"谁在什么时候发 TRIG" |
| **有 `0x5A` 的大块写（≈8 KB 或它的整数倍）** | ★★ **这就是波形** | 你已经拿到了"167 条" |
| 对 `0x3F` 有写/读且值为 `0x09` | `GLB_STATE = TRIG` ⇒ 有人配置过它 | 与 §19.25.6 的判据吻合 |
| 全是 `0x2C` | 抓对了私有总线，但 AW86927 没人访问 | 同上第 1 行 |

**工具产出**（`--outdir` 目录下）
- `aw86927_replay.json` —— 带时间戳、寄存器名、CRC16 的结构化表
- **`aw86927_replay.h`** —— 可直接 `#include` 的 C 数组 + `g_replay[]` 步骤表

## 七、★★★ 抓到之后怎么用（三种用法，按现实性排序）

### 用法 1：自己驱动（蓝莓路线，最现实）
把 `aw86927_replay.h` 编进你的 MCU（ESP32-S3 / STM32），**MCU 当 I²C 主机回放这张表** → AW86927 被配置 + 波形进 SRAM → 拉 `TRIG` → **LRA 响**。

**注意**：必须先让 GT7868Q 让出总线。可行做法（代价从小到大）：
1. **拉低 AW86927 的 `RSTN`（pin1）** → 芯片进 shutdown、输出高阻；你独占 I²C。
2. I²C 写 `GLB_STATE = 0000 (STANDBY)`。
3. 割断 `HDP`/`HDN` 走线（不可逆，最后手段）。

> ★ 如果第 1 行判据成立（**触觉未启用**），那就**根本不需要争夺** —— AW86927 本来就是空闲的，直接接管即可。

### 用法 2：给"改固件"提供靶子
拿抓到的波形字节，**在载荷 A / 载荷 B 里搜**。搜到 ⇒ 定位波形表在 GT7868Q 固件里的偏移 ⇒ 以后想换波形/改强度就有了准确地址（但要过 UEFI 胶囊签名）。

### 用法 3：★ 可能翻案 —— 直接检验 §19.28.6
本项目 §19.28.6 用**四项统计判据**（幅值域/自相关/512B 重复）**否证**了"载荷 A 的 8 个 8 KB 块是波形"。
**那是统计判据，不是逐字节比对。**
> **现在你手里会有真波形 ⇒ 直接和那 8 个 8 KB 块做逐字节比对。**
> - 相同 ⇒ **§19.28.6 的否证要推翻**，波形一直就在手边。
> - 不同 ⇒ §19.28.6 得到**独立确认**（这次是硬判据，不是统计）。

## 八、失败模式与处理

| 症状 | 原因 | 处理 |
|---|---|---|
| 工具解析出 0 个事务 | CSV 格式没识别 | 跑 `--sniff` 看诊断；再按 `t,addr,rw,data` 简易格式自己转一遍（最稳） |
| 全是 `0x2C`，无 `0x5A` | 要么抓对了但触觉未启用，要么抓错总线 | 先用通断档确认抓的是私有总线（§二） |
| 大块写长度不是 8 KB | 可能分页写入/压缩/不是波形 | 看 `事务长度` 分布；8 KB SRAM 是硬规格，分页也可能 |
| 丢包、CRC 报错 | 采样率太低或引线太长 | 提到 25 MS/s；剪短引线；必要时加 100 Ω 串阻（**慎**） |
| 采到的窗口里什么都没有 | 波形下载在更早/更晚 | 回第 1 轮，延长到 60 s 自由采 |
