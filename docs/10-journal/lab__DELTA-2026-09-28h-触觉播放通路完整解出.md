## 0. 一句话

**「播放」不是一个函数。是 `main()` 里无条件初始化的两个定时器
（TIM2 = 200 Hz / TIM3 = 400 Hz），外加一个零调用者的手动入口 `0x0800D628`。
波形（手感）不在这个镜像里。**

## 1. 修正三条既有结论

### 1.1 「TIM1/TIM8 CCER 读-改-写 ×21 处、散落全镜像」→ 错

实际：**21 处全在同一个函数 `0x080105AC` 内**，是它的 **3 个 case 分支**：

| 簇 | 地址 | TIM1 | TIM8 |
|---|---|---|---|
| case 0 | `0x08010604` / `0x08010614` | ×1 | ×3 |
| case 1 | `0x080106BA` / `0x080106CA` | ×1 | ×3 |
| case 2 | `0x08010778` / `0x08010788` | ×1 | ×3 |

⇒ 「运行时调制」应改为「**1 个通道配置函数，3 个 case，各覆盖 TIM1/TIM8**」。

### 1.2 「单端 PWM、无互补输出」→ 不准确

`0x080105AC` 的 case 1/2/3 明确在写 **CCxNE / CCxNP**（互补通道使能 + 极性）：

```asm
; case 1（0x08010684）
08010696  orr.w r0,r0,r2,lsl #4    ; ★ 左移 4 = CC1NE/CC1NP 位域
; case 2（0x08010742）
08010754  orr.w r0,r0,r2,lsl #8    ; ★ 左移 8
; case 3（0x08010800）
08010812  orr.w r0,r0,r2,lsl #12   ; ★ 左移 12
```

**没有写 BDTR（死区）≠ 没有互补输出。** STM32F1 高级定时器允许开互补而 DTG=0。
⇒ 准确说法：**支持互补输出，但未启用死区。**

### 1.3 「`0x0800D628` = 启动 TIM3 的播放函数，零调用者 ⇒ 测试固件」→ 论据作废

- `0x0800D628` **确实零调用者**（这点原判断对）
- 但它**不是播放函数**，而是「**就绪后手动触发一次回调**」的入口：

```asm
0800D628  push {r7,lr}
0800D62A  movw r0,#0x400 / movt #0x4000    ; TIM3
0800D634  bl   0x8010d44                   ; 查就绪标志
0800D638  cbz  r0,#0x800d658               ; 未就绪 → 返回
0800D646  bl   0x8010d30                   ; 清标志
0800D652  bl   0x800d858                   ; 经函数指针槽触发回调
```

- **零调用者 ≠ 死代码**：本镜像 13 个零调用者入口中，`0x08008978` 已确认是 ISR
  （事件分派器，见 `DELTA-2026-09-28g`）。

## 2. ★ 真正的播放器：`0x0800D704`

### 2.1 全部调用者（只有 2 个，参数全硬编码）

| 调用点 | 所在包装函数 | 定时器 | PSC | ARR | 频率 |
|---|---|---|---|---|---|
| `0x0800E03E` | `0x0800DFE8` | **TIM2** `0x40000000` | 119 | **1999** | **200 Hz** |
| `0x0800E784` | `0x0800E750` | **TIM3** `0x40000400` | 119 | **999** | **400 Hz** |

两个包装函数结构镜像对称，**无任何 `cmp`/`cbz` 分支** ⇒ 两段固定波形。

### 2.2 启动 PWM 的关键序列（实锤）

```asm
0800D750  bl   0x8010bf0     ; 时基配置
0800D760  movs r1,#1         ; ★ 通道位掩码 = 1（通道 1）
0800D766  bl   0x80105ac     ; ★★ CCER 配置器
0800D76E  mov.w r2,#0x2bc    ; ★★ 0x2BC = 700
0800D772  bl   0x8010908     ; ★★ 设 CCR
0800D794  bl   0x8010598     ; 使能输出
0800D7A2  orr  r0,r0,#1; strb r0,[r1]   ; 置"已启动"标志
```

**⇒ 占空比 700/2000 = 35% 由猜测升级为实锤。**

### 2.3 回调槽机制

`0x0800D858` 是**间接调用跳板**：

```asm
0800D858  push {r7,lr}
0800D860  ldr  r0,[r0,#0x14]     ; ★ 取函数指针
0800D862  blx  r0                ; ★★ 间接调用
```

`0x0800E782` 写 `str r1,[r0,#0x14]`（存 `0x0800D6F5`）⇒ **`[ctx+0x14]` = 定时器回调槽。**

## 3. ★★ 触觉定时器在 `main()` 里被无条件初始化

`0x0800E1C0`（命令分派器）的调用者是 `0x0800FDFA`，位于函数 `0x0800FA20` 内，
该函数含「初始化接力 + 无限主循环」：

```asm
0800FD7C  bl 0x800dfe8     ; ★★ TIM2 = 200 Hz
0800FD80  bl 0x800e750     ; ★★ TIM3 = 400 Hz
...
0800FDF4  bl 0x8008c64     ; ┐
0800FDFA  bl 0x800e1c0     ; │ ★ 命令分派器
0800FE06..0800FE34         ; │ 共 8 个调用
0800FE38  b  #0x800fdf4    ; ┘ ★ 无限主循环
```

**⇒ 两个触觉定时器在主循环前初始化完毕，无条件、无参数。**

## 4. 可达性统计（新工具 `callgraph.py`）

| 指标 | 值 |
|---|---|
| 函数入口（`push {...,lr}`） | **136** |
| 从 main `0x0800FA20` 可达 | **110** |
| 不可达 | **26**（ISR 向量 + 间接调用目标 + 真死代码） |
| TIM2包装 / TIM3包装 / 播放器 / 分派器 | ✅ 全部可达 |

⚠️ **工具局限**：只扫直接 `bl`/`b`，不解析函数指针 ⇒ 把间接调用目标误判为"不可达"。
实例：`0x080105AC`（CCER 配置器）显示不可达 = **假阴性**。
判死代码需三条件同时满足：① 直接图零入度 ② 无函数指针写入 ③ 不在向量表位置。

## 5. 对方案③（HDP/HDN 旁路）的净影响

### 5.1 新增 6 条可直接照抄的规格

| 项 | 值 |
|---|---|
| 频率 | 200 Hz（A）/ 400 Hz（B） |
| 占空比 | 700/2000 = **35%** |
| 通道 | **通道 1（CC1E）** |
| 互补输出 | 支持（CCxNE/CCxNP 可配），**未设死区** |
| 定时器对 | TIM2（`0x40000000`）/ TIM3（`0x40000400`） |
| 波形来源 | **硬编码**，无主机下发路径 |

### 5.2 波形不在明文段 —— 但"在哪"仍开放

- 包装函数参数全硬编码，无取波形路径
- 回调 `0x0800D6F5` 只是计数器（`ldr; adds #1; str`）
- ⇒ 手感不在 TF100A 明文段 ⇒ **支持"包络由加密 TP 侧下发"的倾向判断**

⚠️ 但**不等于已证实**。另两种可能未排除：
① 包络在 TF100A **自己的加密段**（100 KB）；
② 包络在 **GT7868Q 侧**。
56 KB 明文段只是"定时器驱动层"。

### 5.3 本项处置：**降级但不作废**

- **降级**：确认手感不在明文段（符合预判）
- **不作废**：净赚 6 条驱动规格，可直接用于方案③ 初始化序列
- **剩余缺口仍是 2 个**：**振幅** + **LRA 型号/谐振频率**（与 `DELTA-2026-09-28` 一致）

## 7. 教训

1. **数量 ≠ 分布**。「21 处」听起来像散落全镜像，实测是同函数 3 个 case。
   **先定位再解读，别拿数量当结构性证据。**
2. **零调用者 ≠ 死代码**。本镜像已有 ISR 先例。以"零调用者"作结论时，
   必须补"需排除向量表 / 函数指针触发"。
3. **静态调用图必须自带局限声明**。否则会得出"CCER 配置器是死代码"的荒谬结论。
4. **包装函数要读全**。`0x0800DFE8` 与 `0x0800E750` 只差 3 个常量
   （定时器基址 / ARR / 回调地址），结构完全镜像 —— 看到第一个就该猜第二个。
