## §1 新工具：`tools/analysis/lab__ref_check.py`（悬挂编号引用）

| 项 | 内容 |
|---|---|
| 为什么 | 文件链接已有检查器；但 **编号引用**（`§19.x` / `B<n>` / `纪律 <n>`）没人管 —— 引一个不存在的章节号，读者找不到东西，而链接检查看不见 |
| 做法 | 先从档案算出三个上限（`§19.<84>` · `B<66>` · `纪律<179>`），再扫全文找越界 |
| 自对照 | **2 项**：阳性（把三个上限各抬高一位造越界 ⇒ 报 3 处）· 阴性（范围内 ⇒ 报 0 处）⇒ **全通过** |
| 结果 | 全库 **§19.x 越界 0 · 纪律 越界 0 · B 越界 0**（清零前 22 → 21 → 1 → 0，全部为**假阳性**修正 + 1 处夹具改写） |
