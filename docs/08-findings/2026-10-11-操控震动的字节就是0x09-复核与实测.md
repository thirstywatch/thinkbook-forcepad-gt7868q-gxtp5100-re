# 2026-10-11 · 「操控震动的字节」= `0x09`（复核 + 可复现实测 + 两处方法学失误）

> 提问：**"操控震动的字节是哪一个？能不能找到？直接实验"**
> 结论：**`0x09`**。而且 **2026-10-08 第 22 轮就已经找到并实证过**（登记表 **B14**）。
> 本轮做的是：**工具重建 + 可复现实测 + 顺手清掉两条错的中间结论**。
> 全文见《全书》**§19.47**。

## 一、答案

| 项 | 值 |
|---|---|
| **字节** | **`0x09`** = **Col02 的 HID Feature Report RID 9** |
| **HID 身份** | Usage Page `0x0E`（HID 触觉页）· Usage `0x23`（Intensity）· 8 bit × 1 |
| **取值** | **`0` = 完全静音** · 中间 = 渐强 · **`100` = 满档** |
| **写法** | `HidD_SetFeature(h, {0x09, v}, 2)`；句柄 **`GENERIC_WRITE` 单开**（Col02 的 READ 被 Col03 占，SetFeature 只需写权限）⇒ **不需要管理员、不需要禁设备** |
| **Windows 关系** | 设置里「触觉点击」开关联动写的就是它（关 = `0` / 开 = `100`） |
| **易失** | 不落盘；外部改写后 UI 与硬件脱钩 ⇒ UI 里"关一下再开"或重启 |
| **✅ 已实证** | 写 `0` ⇒ 用户反馈"没震动反馈了"；写回 `100` ⇒ 恢复 |
| **❌ 做不到** | **"任意时刻主动触发震动"** —— 缺 `0x0E/0x21 Manual Trigger`。`0x09` 只决定"设备自主触发时用多大劲" |

**⇒ 主机侧唯一经实测确认能改变震动表现的注入面，就是它。**
**⇒ 其余全部阴性**（Col04 内存写 / cfg 写入 / AW86927 直连 / 固件明文段），原因见《全书》§19.34.5：
**震动触发在「固件 ↔ 主机 I²C 通信层」，不在内存数据层。**

## 三、🔴 我今天犯的错：漏掉 `0` 档（再犯纪律 114）

第一次运行我排了 `1 / 50 / 100 / 10`，**唯独没有 `0`**。
而登记表 **B14 的纪律 114** 明确写着：

> **实测一个"开关型"字段时，必须包含【0 = 关】这一档。**
> 只测"大 vs 中"（如 10 vs 100）得到"无差别"的阴性，**不能断言通道无效** ——
> 因为开关型字段的可见效应在**极端档**（0 vs 满值），不在中间段。

**根因**：我按描述符的 `log=100..1` 推断"`0` 越界"，**没先检索登记表**（纪律 115/116 的同类错误）。
**⇒ 这是"描述符逻辑域 ≠ 设备接受域"的实例 ⇒ 立为纪律 135。**

## 四、顺手清掉的两条错中间结论

### 4.1 `0x96F8` 活体区 **不能** 与历史快照做差分（登记表 B27）

想用 `data/reference/lab__cfg_record_orig_1084.bin`（2026-10-05 保存）当健康基线，
与活体 `0x96F8` 起 1084 B 差分 ⇒ 得到"差异 780 / 1084"。

**🔴 但这个差异是假的**：`0x96F8` 是**分时复用 RAM 窗口**，显示的是"固件此刻正在用的那一块"。
旁证：本轮连读 3 次，64 B 里 **63 B 稳定、仅 `+0x2F` 抖动** ⇒ 秒级稳定成立、**跨时刻不成立**。
**⇒ 该差分方法作废 ⇒ 立为纪律 136。**

### 4.2 `0x1800` / `0x3800` = "触觉参数区" → 定名降为【存疑】（登记表 B26）

| 区 | 15:01 健康 | 15:29 当前 | 15:31（`lab__r51`） |
|---|---|---|---|
| `0x1800` | 全 `00` | 全 `00` | `3C 00 00 00 3C 00 00 00 … 80 0F …`（**非零**） |
| `0x3800` | 全 `00` | 全 `00` | — |

⇒ 内容**随时刻变化**且**只读**（写入后读回 12/20 不一致）
⇒ 更像**活标定/临时区**，不是静态触觉参数表 ⇒ 立为纪律 137。

### 4.3 写权限表复核（与既有记录一致）

| 区 | 可写？ |
|---|---|
| `0x1800` / `0x3800` / `0x1060` / `0x9A00` | ❌ 只读 |
| `0x1C00` / `0x4000` / `0x5F00` | ✅ 可写 |
