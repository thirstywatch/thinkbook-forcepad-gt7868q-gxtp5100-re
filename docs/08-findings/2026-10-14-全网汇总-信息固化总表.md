### 3.4 ★★★ 补全 §19.40.2 的解释

⇒ **r13 第 1 轮的失败正是"同一地址 + cont=1"，与厂商语义完全一致。**

## §5 ★★★★ 「能不能造出不缺 `0x0E/0x21 Manual Trigger`」—— 网上资料 + 判定

### 5.1 网上查到的决定性事实

| 来源 | 原文/要点 |
|---|---|
| **微软《疑難排解 HID over I2C 裝置問題》** | 「**作業系統會根據 HID 描述符的資訊擷取 HID 報告描述符。HID 描述符會從【裝置韌體】中提前取得。**」<br>⇒ **I²C-HID 的描述符来自设备固件**（`wReportDescRegister` 指向设备内寄存器）⇒ **主机侧无法替换** |
| **Linux `i2c_hid_output_raw_report`**（Torvalds 补丁） | `i2c_hid_set_or_send_report(client, 0x02, report_id, buf, count, use_data)` —— **内核不校验描述符** ⇒ **主机侧能发"未声明的 report ID"** |
| **vJoy**（DeepWiki） | 它的虚拟设备从**注册表**读 `HidReportDescriptor`（`HKLM\…\services\vjoy\Parameters\DeviceXX`）⇒ **那是它自己的驱动**，**不适用于 HIDI2C.SYS 管的真实设备** |
| 微软《Input Device Haptics Implementation Guide》 | 主机发起需 `0x0E/0x01` 集合 + Waveform List/Duration List（Feature）+ **Manual Trigger（Output）** |

### 5.2 ★★★★★ 判定：**要分【主机侧】与【设备侧】两问**（纪律 33 正是为此而立）

| 层 | 能否造出 Manual Trigger | 依据 |
|---|---|---|
| **① 主机侧描述符** | ✅ **能** —— 内核驱动 `report_fixup` 可改（本项目已找到针对本机 PID `0x01E9` 的现成反例）；Linux 下可直接改 rdesc | §19.30.1 |
| **② Windows 是否因此暴露 SimpleHapticsController** | ⚠️ **可能能**（HID 栈按描述符建 caps）；但 `InputHapticsManager` 另有**设备白名单** | 未证 |
| **③ 应用发 Manual Trigger OUTPUT 报文** | ✅ **能发** —— **I²C-HID 的 SET_REPORT 不校验描述符**（见 5.1 第 2 条）⇒ **报文会真的送到 IC** | ✅ 已证 |
| **④ IC 固件是否执行** | ❌ **这才是决定性的** | §19.30 已定案「设备侧无接收分支」；**本轮新增支持证据**：厂商 DLL **只发 `0E 20`，从不使用任何 OUTPUT 报告机制** ⇒ **该 IC 的 HID 固件里没有 output-report 功能面** |

**⇒ 结论：主机侧"能造"，设备侧"不认" ⇒ 强制触发仍然不可能。**
**⇒ 而且"改描述符让它以为能控制"的最终形态 = 让 Windows 以为能控制、实际石沉大海（§19.30.1 已述）。**

- **120** = 历史 `+0x115`（"强度旋钮"候选，**已降级为存疑**）
- **⇒ bag 6 = 几何 + 若干参数，不是触觉袋**

### 6.4 ★★★★★ E 面实验设计（唯一有希望的暴力面）

**原则**：① 每袋一次会话写入（合法重算校验尾）② 判据用 `vib_probe.py`（J1 客观）③ 结果码必须 `0x7F`，否则本次无效 ④ **一次只动一个袋**

| 序 | 动作 | 判据 |
|---|---|---|
| 0 | `vib_probe.py calibrate`（按 5 次触控板） | 能检出 ≥3 次事件 ⇒ J1 可用 |
| 1 | **原样写回**（对照） | 结果码 `7E 00 07`（复现预言机） |
| 2 | 逐袋**整袋清零**（27 次，每次一个袋） | 结果码 `0x7F` **且** 震动**客观变化**（时长/幅度/有无） |
| 3 | 若第 2 步无变化 ⇒ 逐袋**替换为 0xFF** | 同上 |
| 4 | 只在"有变化"的袋里做单字段细扫 | 同上 |

**⇒ 若 27 袋扫完、震动行为**完全无客观变化** ⇒ **cfg 里没有"事件层"字段** ⇒
**「滑动震动」在本机硬件上不可能** —— 且该结论是**穷尽后的**。
