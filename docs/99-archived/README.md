## ★★ 读之前必须知道：这些结论**全部已被推翻**

| # | 本目录里的结论 | 现状 |
|---|---|---|
| 1 | **`K` 不是密钥**（第十六轮，E1–E5 五条"决定性证据"） | 🔴 **作废** —— 五条全是**循环论证**：只要明文里有全零段，`raw = plain ⊕ K` **必然**让 raw 出现 K 副本。这是**支持**证据，被读成了否证。**代价：整条加扰线被关闭两天** |
| 2 | **「固件被加扰/加密」这个前提整体作废**（第十八轮） | 🔴 **作废** —— 加扰成立且已解出（1024 B 周期 XOR，相位 316） |
| 3 | **GT7868Q = 8051 + Cortex-M4F 双核混合** | 🔴 **整条作废** —— 那段 ARM 是 **TF100A**；GT7868Q = **8051/Turbo51**（代码在 mask ROM）。且 TF100A 是 **Cortex-M3**，不是 M4F |
| 4 | **`GT7868Q_plain.bin` 是明文固件** | 🔴 **作废** |
| 5 | **`tpfw.bin`（magic `PNOR_G1`）是官方明文固件** | 🔴 **推翻** —— `PNOR_G1` 只是 `firmware_info.hw_pid[6]` 字段，体部同样被 `K` 加扰 |
| 6 | **GT9896 的解也一并作废**（§10.6.4b） | 🔴 **撤回这个撤回** —— GT9896 那份**是有效的**。连带作废而无新证据，是第二种错误 |
| 7 | **`0x5A` = AW86927 的 I²C 从地址** | 🔴 **已撤回** —— 三重检验均不成立，实为 Goodix host command 描述符里的数值参数 |
| 8 | **`追加二十七` §五：TF100A 只做 I²C 从机**（那条**证据链**） | 🔴 **整段作废** —— 核心地址 `0x0800894C` 落在 **K 交织表副本** `[0x08800,0x08C00)` 内（`udf` 率 0.0548 vs 真代码 0.0020）⇒ 把数据表字节误读成指令。**⚠️ 但结论本身保留**（新依据：`I2C_Init@0x0800FA20` 逐指令） |
| 9 | **「上层 HID 过滤器驱动」/「并列 SPB 客户端驱动」** 两条绕行路线 | 🔴 **已排除**；微软：同一外设的连接同时只能一家持有 |
| 10 | **§6.3「70/48 全 0 命中」** | 🔴 是**采样不足**造成的假否定 |
| 11 | cfg 的**二级子记录语法 `0x5C30/0x5D0C/0x5E0C/0x5F16`** | 🔴 是 `[LEN][TAG]` 两字节被**反读**（真实帧序 `[LEN][TAG]`） |
