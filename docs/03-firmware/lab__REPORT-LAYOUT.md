# Col02（PTP）40 字节输入报表 —— **实测字段布局**

> 数据来源：`DumpPad.exe 40 -q`（2026-09-13）· 3374 条真实报表 · 6 种手指动作全覆盖
> 采集方式：只读 Raw Input（`RIDEV_INPUTSINK`，usage page `0x0D` / usage `0x05`）—— 不打开设备、不发命令，零风险

## 布局（已验证）

| 偏移 | 内容 | 实测取值范围 |
|---|---|---|
| `0` | **报表 ID = `0x04`**（恒定） | `0x04` |
| `1` | 触点0：**低 4 位 = 按键位 / 高 4 位 = 触点 ID** | `0x01`–`0x13` |
| `2-3` | 触点0 **X**（u16 LE） | `0x0500`–`0x0BFF`（**1280–3071**）|
| `4-5` | 触点0 **Y**（u16 LE） | `0x0000`–`0x07FF`（**0–2047**）|
| `6-7` | 触点0 **压力**（u16 LE） | `0x0000`–`0x01F1`（**0–497**）|
| `8` | 触点1：按键位 / 触点 ID | `0x00`–`0x13` |
| `9-10` | 触点1 X | `0`–`0x0BFF` |
| `11-12` | 触点1 Y | `0`–`0x07FF` |
| `13-14` | 触点1 压力 | `0`–`0x4B`（本次最多 2 指，故偏小）|
| `15-21` | 触点2（X/Y/压力） | 本次全 0（未做 3 指）|
| `22-28` | 触点3 | 全 0 |
| `29-35` | 触点4 | 全 0 |
| `36-37` | **扫描时间**（u16 LE） | `0x0000`–`0xFFFF` |
| `38` | **接触数** | `0x01`–`0x02`（本次最多 2 指）|
| `39` | **bit0 = 按下（点击）状态** | `0x00`–`0x01` |

**合计 40 字节** ✅（7 字节/触点 × 5 + 2 扫描时间 + 1 接触数 + 1 按键）

## 坐标与阈值（供手势引擎使用）

| 参数 | 值 |
|---|---|
| X 逻辑范围（实测最大值） | **3071**（`0x0BFF`，12 bit） |
| Y 逻辑范围（实测最大值） | **2047**（`0x07FF`，11 bit） |
| 边缘区宽度建议 | 4% ⇒ 右边缘 X ≥ **2950**、左边缘 X ≤ **123** |
| 点击（按下）判定 | `byte[39] & 1`；压力阈值实测 ≈ **141–149**（用力可达 ~497）|

## 与旧笔记的差异（以本文实测为准）

- 旧笔记写"`byte0=报文ID`"没错，但**具体值是 `0x04`**（不是 `0x0E`）——`0x0E` 是 Col04 厂商集合的报表 ID。
- 触点数据为**每触点 7 字节**结构，第 2 触点在偏移 `8` 开始（旧笔记的 `X@2/Y@4/压力@6` 只描述了**第 1 触点**）。

## 复现方式

```
csc /nologo /target:exe /out:DumpPad.exe DumpPad.cs
DumpPad.exe 40 -q      # -q 只输出统计（各字节偏移取值范围），便于测绘字段
DumpPad.exe 20         # 不带 -q：逐条打印原始字节 + 猜测字段，用于核对
```
