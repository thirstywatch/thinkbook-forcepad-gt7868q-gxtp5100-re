# 99 · 踩坑清单（102 条纪律精选）

> 本项目 3 周 20 轮沉淀的纪律，按类别整理。
> **每条都对应一次真实返工。** 编号沿用原档案（§19.x 末尾"纪律"小节）。

---

## A. 判据类（最容易翻车）

| # | 纪律 |
|---|---|
| 1 | 🔴 **没有阳性对照的"读不到"是无效结论。** "搜不到" ≠ "不存在" |
| 2 | 🔴 **负面结论必须有同类对照样本**，否则不算数 |
| 3 | 🔴 **"覆盖率/消费率"型判据必须做【真代码·随机·全零·纯文本】四类反例标定**。凡判据在全零/文本上也给高分，就不能用来判代码 |
| 4 | 🔴 **"某模式重复率高于随机"之后，必须再问「重复的是什么」** —— 可能只是零填充 |
| 5 | 🔴 **关闭一条已积累证据的路，需要比打开它更强的证据**。「模式出现多次」「统计量偏离随机」都不够；**多份独立样本交叉且过拟合不可能产生**才够 |
| 6 | 🔴 **密钥候选来自数据自身时，"出现次数"没有判据力**（循环）。改用：直方图配平 + 相位穷举 + 多样本交叉 + 解出后整块零填充 |
| 7 | **不要用错误的窗口做统计。** 先解容器 → 拿块边界 → 再统计 |
| 8 | 🔴 **"正确地撤回错误结论"也可能做错。** 撤回也要带新证据，不能靠"它和被否掉的那条方法相似" |
| 9 | 🔴 **零阶熵 H0≈8.0 是非特异判据** —— 白化/压缩/加扰/密文/真随机**全都**给 ~8.0 |
| 10 | **三项定量判据（可压比 / H1−H0 / 自相关）能排除分组密码与压缩，但排除不了周期 XOR 加扰** |
| 11 | 🔴 **"解出来不是代码"可能比"解不开"更难缠** —— 那不是解密失败，是内容问题 |
| 12 | **观测判据必须报"灵敏度"**。"全零"只能得出"在此灵敏度下未见" |
| 13 | **投资优先级 = 证据强度 × 可改性**，缺一即降级 |

## B. 分层 / 符号类

| # | 纪律 |
|---|---|
| 14 | ★★★★★ **命令有四张表，绝对别混**（TF100A 39 条 / GT7868Q 16 条中继副本 / 官方命令集 ~10 条 / 主机报文 6 种） |
| 15 | **同一个符号可能指不同东西**（`0x2C` 在两个总线层、`0x1800` 在两套含义）。**引用时必须加限定词** |
| 16 | **大部分"矛盾"不是结论冲突，而是符号没加限定。** 修法不是"选一个"，是加限定 |
| 17 | **两个程序、两套地址空间，不得混表**（GT7868Q vs TF100A） |
| 18 | **跨层推断要显式声明**。"外层是 UEFI 合约"推不出"内层不是加密固件" |
| 19 | **不要把 TF100A 的 39 条当成 GT7868Q 的** |
| 20 | **不要把 `.cfg.txt` 直接当 cfg 载荷下发** |

## C. 反汇编类

| # | 纪律 |
|---|---|
| 21 | 🔴 **验证 ARM/Thumb 的 imm32 常量必须反汇编或解码 MOVW/MOVT 配对，绝不能字节搜索** |
| 22 | **基址必须三重交叉验证**，不要默认 `0x08000000` |
| 23 | **`0xA2` 是异步产物，不是命令的同步应答** ⇒ "没收到 `A2`"不能证明设备拒绝 |
| 24 | **`0x20004090` 是 16 字节控制块**，那三个 `cmp #N` 不是子命令编号 |
| 25 | **镜像开头 = 标准 ARM 运行库** ⇒ 这是"解析正确"的最强佐证 |
| 26 | **全镜像只有 5 个真字符串** ⇒ 不要指望靠字符串定位功能 |
| 27 | **曾用错 ISA**：芯片核是 8051（Turbo51），却只测了 ARM/RISC-V ⇒ **先确认架构再选工具** |

## D. 协议 / 真机类

| # | 纪律 |
|---|---|
| 28 | 🔴 **`Gx::Write` 帧长度字段是 `+5`，不是 `+7`** ⇒ 用错则每一帧被静默丢弃，结论全错 |
| 29 | 🔴 **读回字节序取决于请求地址的低 2 位** |
| 30 | **单次事务 ≤ 32 B，间隔 ≥ 500 ms，禁止批量轮询 `Col04`** |
| 31 | **红线是四条，不是三条**（`00 10`/`00 11`/**`0E 12`**/`0E 13`），`0E 12` 才是真正写 flash |
| 32 | **写入类命令置于最后，且先确认通道真的打开** |
| 33 | **`0xFF` = 空闲是常态**，写完命令后字节0 回 `FF` **不是接受信号** |
| 34 | **`0x82` 仅为命令 `0x80` 的应答**，需等约 250 ms |
| 35 | **`0x1800`/`0x3800` 读得出但读不稳** ⇒ 不可作数据、更不能据此做写实验 |
| 36 | **`0x20` 读的单报表上限 = 60 B** |
| 37 | **32 位地址读已判否**（带阳性对照） |
| 38 | **不要以为装 Linux 就能读写参数区** —— 实测 Linux 下触控板根本不工作 |
| 39 | **Linux 上 `lost arbitration` 不要过度解读** |
| 40 | **触控板那条总线上 `i2cdetect` 会崩内核** |
| 41 | **不要用 ETW 判断"有没有 OUT 报告"** —— provider 无 Write 事件 ⇒ 必然假阴性 |
| 42 | **RWEverything 的 `Access → I²C/SMBus` 走的是 PCH SMBus，不是触控板的 I2C0 MMIO** ⇒ 照它做必然假阴性 |
| 43 | **先解绑 `i2c_hid` 再扫**，否则总线不静 |

## E. 工具链类

| # | 纪律 |
|---|---|
| 44 | 🔴 **不要用正则批量写文件** —— 曾把 12,000 行档案截断成 24 行 |
| 45 | **大改前先快照** |
| 46 | **所有 ps1 脚本纯 ASCII**（PS 5.1 按 GBK 解读非 ASCII） |
| 47 | 🔴 **ps1 交付前跑官方解析器** `[ScriptBlock]::Create`。"数括号"式检查查不出**多行 `-f`** 与**多重 BOM** |
| 48 | **bat 正文一律纯 ASCII（+CRLF）**，提权行带中文会被啃掉（`chcp 65001` 也救不了） |
| 49 | **PowerShell 脚本给 v5.1 必须带 UTF-8 BOM**（且只能 1 个） |
| 50 | **env 大小写重复变量**（`Path/PATH`）会让 `Start-Process` 抛"字典已添加项" |
| 51 | **分清"agent 能跑的"与"只能用户跑的"**：shell 派生 = 用户；普通 exe = agent |
| 52 | **用户侧脚本必须自带诊断落盘**（提权成败 / 退出码 / 结果文件新鲜度），否则"假 DONE-OK" |
| 53 | **iasl 反编译不能用 `-o <path>`**（报 `Option requires a single-character suboption: -o`） |
| 54 | **ACPI 表键 `SSD1..SSDS` 是平级表键，不是 SSDT 的子键** ⇒ 遍历错了只导出 3 张表 |
| 55 | **PawnIO 需管理员**（`0x80070005` = 权限不足）；**纯 HID 工具不需要** |
| 56 | **PawnIO 校验 RSA-4096 签名** ⇒ 自写模块要么提交上游，要么装 Unrestricted edition（需关 Secure Boot） |
| 57 | **RWE 脚本变量名只能是 `Local0`–`LocalF`** —— 超出的脚本"看起来完好、从未成功执行过" |
| 58 | **RWE `/LogFile` 会静默失败** |

## F. 方法学类

| # | 纪律 |
|---|---|
| 59 | 🔴 **"有字节级目标" ≠ "可以改"**。每个被改字节必须反汇编互证；补丁后立即做"仅 N 字节差异"证明 + 双 sha256 存档 |
| 60 | **发现"正确答案"时不要急着否掉它** —— `rot_left(K,316)` 在文档里躺了两天 |
| 61 | **"主机侧没有密钥"要做判决性测试，不能靠推理** |
| 62 | **先穷举再下结论**（相位 1024 个穷举一遍只要几秒） |
| 63 | **多样本交叉是"防过拟合"的唯一廉价手段** |
| 64 | **从"现象"反向追溯，比从"命令"正向猜有效**（输出端追溯是本项目最大推进） |
| 65 | **淘汰法要检查边界是否漏了候选** —— 本项目漏了 EC，直到外部提醒才发现 |
| 66 | **"搜索 0 命中"要检查搜索本身** —— 六路搜索 0 命中，可能只是没搜对地方 |
| 67 | **横向找同构产品对照**（Surface / 蓝莓 ESP32）能快速定性 |
| 68 | **官方源码是最强依据**，但**要拿全**（曾漏 `gtx2/` 那一层，一直拿不到官方命令表） |
| 69 | **与官方实现对账能发现自己的 bug**（`+5` vs `+7` 就是这样找到的） |
| 70 | **保留已作废结论**并加横幅 —— 删掉会让别人重踩 |

## 附：本项目"最贵的五个错"

| # | 错误 | 代价 |
|---|---|---|
| 1 | 把「K 出现在 raw 里」当作「K 不是密钥」（循环论证） | **2 天** |
| 2 | 从"三项判据偏离随机"外推"没有加扰" | 定性错误 |
| 3 | 窗口边界错（`0x1400–0x19800`） | 后续所有统计跑偏 |
| 4 | 从未用正确的 ISA 测过（芯片是 8051，只测了 ARM/RISC-V） | 漏项 |
| 5 | 淘汰法边界错误，把 EC 挡在门外 | 多走一轮 |
