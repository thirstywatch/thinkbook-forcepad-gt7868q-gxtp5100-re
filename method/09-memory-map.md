# 09 · 内存地图 · 地址与常量速查

> **是什么**：本项目涉及的全部地址空间与常量，按"层"整理。**引用任何地址前先查这张表，并带上"哪条总线 / 哪一层 / 哪个器件"的限定。**
> **做什么**：按层查找。
> **得到什么**：一张能防止"把 A 器件的地址用到 B 器件上"的对照表。

---

## 0. ★ 四层地址空间（先分清）

| 层 | 属于 | 典型范围 |
|---|---|---|
| **① 主机 I²C 总线地址** | 主机 → 设备 | `0x2C`（GT7868Q）、`0x5A`/`0x5B`（AW86927） |
| **② I²C-HID 寄存器** | 协议层 | `0x20`–`0x25` |
| **③ 触控 IC 内部 RAM/寄存器** | GT7868Q 片内 | `0x1800`、`0x2000`、`0x4160`、`0x96F8` … |
| **④ TF100A 片内（STM32 兼容）** | TF100A 片内 | `0x08005000+`（flash）、`0x20000000+`（SRAM）、`0x40000000+`（外设） |

> 🔴 **③ 和 ④ 是两颗不同的芯片，地址不得混用。** 本项目曾因此产生 5 项连带更正。

## D. 触控 IC 寄存器层（GT7868Q 片内）

```
VER_ADDR                    0x4014     // 读 32B，末 2B 校验和
CMD_ADDR                    0x4160
CFG_START_ADDR              0x96F8     // 读 3B 得 cfg 版本
BL_STATE_ADDR               0x5095     // 等 0xDD
FLASH_RESULT_ADDR           0x5096     // 等 0xAA
FLASH_BUFFER_ADDR           0xC000
CFG_FLASH_ADDR              0x19000
参数区 A                    0x1800     (27 B)   ← 触觉
参数区 B                    0x3800     (8 B)    ← 触觉
配置块                      0x2000 (1092B) / 0x2C00 (1092B)
标定字节                    0x0444 / 0x2444 / 0x3044
HW_REG_SCRAMBLE             0x2218     // ★ 是个【可以关掉的开关】，不是密钥
```

> ⚠️ `0x1800` / `0x3800` 有**两套含义**：① 上面这些片内参数区偏移 ② 主机报文类型 4 的写入目标。引用时必须限定。
>
> ⚠️ `0x1800` / `0x3800` **读得出但读不稳** ⇒ 不可作数据。

### D.1 ★★★ GT7868Q 32 KB 内存地图（2026-10-03 首次完整实测，§19.34.2）

> 由 Col04 `class 0x20` 读通道逐段测绘得到。**这是"能用软件看到多少"的物理边界**。

```
0x0000-0x4000  全零（未映射）
0x4000-0x4400  固件信息区（含 "YELSTO" + "7869"，静态）
                0x04000: A7 E0 ED B1 F4 9D CC DC D7 41 71 82 C8 41 DE 95
                0x04010: 32 BE E4 F5 00 87 00 00 59 45 4C 53 54 4F 00 00   "YELSTO"
                0x04020: 06 00 37 38 36 39 00 00 00 00 1C 02 03 05 00 04   "7869"
0x4400-0x5400  触摸数据（活，值域 0x76xx/0x77xx ≈ 30 200）
0x5400-0x6000  混合 ← ★ 0x5F00 = 压力帧族（见 D.2）
0x6000-0x6C00  加密块（熵 H > 7.0）
0x7400-0x7840  加密块
0x7840-0x8C00  活数据（值域 1186–1520，与 HID `Tip Pressure 0..2000` 同域）
0x8C00-0xB000  数据（0xA000+ = 有符号小整数数组，值域 −8..+17）
0xB000-0xC000  数据 + 加密块
0xC000-0xFFFF  全零（未映射）
```

**⇒ 可用空间只有 `0x4000–0xC000`（32 KB）**。低/高地址均未映射
⇒ **"全 64 KB 扫描"实际等价于扫这 32 KB**；老线"全 64 KB 无命中"的说法据此重估。

### D.2 ★★ 压力帧族（`0x5F00`，本项目此前从未看到）

```
0x5F00 起 = 60 字节/帧；按压时出现 4–5 份完全同步的副本（间隔 0x3C）
帧头: 7F 10 80 00 00 00 00 3C | 00 3C | … | 00 04 (通道数 = 4)
帧尾: … 00 00 00 00 | 28 28 28
```
* 帧头在"静默"时只出现 1 处，"按压"时出现 5 处（`0x5F00`/`0x5F3C`/`0x5F78`/`0x5FB4`/`0x5FF0`）。

| `0x5F21` | u16LE `@0x5F20` | 观测到的状态 |
|---|---|---|
| `0x01` | **334** | 按住（15–45 s 段） |
| `0x02` | **590** | 按住 1.5 分钟 / 手指在板上但未按 |
| `0x03` | **846** | 松开 |

* 低字节恒为 `0x4E`，真正变的是单字节 `0x5F21`。
* ⚠️ 同一"按住"动作出现过 334 与 590 两个值 ⇒ 疑似**力度档位**，尚未完全定标。
* **全 32 KB 里该签名只有 1 处** ⇒ 它是"末端输出"，不是"多处同步的状态"。

**另外两族（同构，语义未定）**

| 族 | 帧头 | 备注 |
|---|---|---|
| `0x5600` 族 | `00 01 01 02 01 05 18 34 13 88 00 30` | 含 `13 88`(=5000)；`+0x1D` 在按压时 0→1 |
| `0x5900` 族 | `7F 10 7F 88` | 含 `88 00`(=136) |

### G.1 `ctx` 结构体（由访问偏移反推）

```c
struct tf100a_ctx {          // 句柄 = 0x20004134 = [0x20004128] + 0xC
  uint8_t  rx_buf[0x80];     // +0x000  接收缓冲（128 B）
  uint8_t  tx_buf[0x80];     // +0x080  发送缓冲（128 B）
  uint16_t tx_idx;           // +0x100  发送计数
  uint16_t rx_idx;           // +0x102  接收计数
  uint8_t  ns;               // +0x104  命名空间 ← 分派器读这里
  uint8_t  _pad;             // +0x105
  uint8_t  ctrl;             // +0x106
  uint8_t  state;            // +0x107
  uint8_t  addr;             // +0x108
  uint32_t speed;            // +0x110  400 kHz
  void (*cb_done)(void);     // +0x114  0x0800DB39
  void (*cb_err)(void);      // +0x118  0x0800DB5D
};
```

**依据**：收包 `strb r1,[r0,r1(rx_idx)]`；发送 `ldrb r1,[r4+0x80+tx_idx]`；**两边溢出阈值都是 `cmp ..., #0x7f`** ⇒ 两个 `0x80` 长的缓冲正好并列，结构自洽。

### G.2 ★ 采样窗口状态机（`ctx+0x1690` 邻域）

| 偏移 | 绝对地址 | 名称 | 语义 |
|---|---|---|---|
| `+0x1690` | `0x20005FEE` | **`armed`** | 待处理标志（`A0/0x0D00` 置 1，主循环任务消费） |
| **`+0x1691`** | **`0x20005FEF`** | ★ **采样窗口开** | `=1` 表示"正在累积" |
| **`+0x1692`** | **`0x20005FF0`** | ★ **累积完成待取走** | `=1` 表示"结果就绪" |
| `+0x1694` | `0x20005FF2` | （不是标志） | 它是**长度** `0x1694 = 5780`，出现在 `A0/0x0D00` 的 `memset` 参数里 |

**全部访问点（机械提取）**：

| 地址 | 操作 | 所属 | 说明 |
|---|---|---|---|
| `0x08009A16` | **写 `+0x1691` = 1** | 函数 **`0x080099EC`** | ★ **开采样窗口** |
| `0x08005BC6` | 读 `+0x1691`，要求 `==1` | **主循环任务 `0x08005BB8`** | 门控 |
| `0x08005C44` | **写 `+0x1691` = 0** | 同上 | 累积满 **300** 次后关窗口 |
| `0x08005C4E` | **写 `+0x1692` = 1** | 同上 | 置"结果就绪" |
| `0x08008794` / `0x080087AC` | 读 `+0x1692`，`==1` 则**清 0** | 函数 **`0x08008784`** | ★ **取走结果 + 回 `A2 10 <16B>`** |
| `0x0800630E` | 写 `+0x1691` | `0x080062xx`（**USART 侧**） | 另一条链路也参与同一状态机 |

> **★ `0x080099EC` 全文只有一句有效逻辑**：`if (msg[0]==1) ctx+0x1691 = 1`

### G.3 ⚠️ 一处未闭合的口径差异

| 出处 | `ctx` 值 |
|---|---|
| 附录 G / §11.2 | `0x20004128`（句柄 `0x20004134`） |
| §11.3.1 | `0x2000495E` |

**两者相差 `0x836`，可能对应不同镜像版本或不同上下文。** 引用 `ctx+0x1690` 类偏移时请注明取自哪一节。

### G.4 震动判据链（可改的字节级目标）

| 项 | 值 |
|---|---|
| 判据 | `\|基线 − 当前\| > 40`（立即数 `0x28`） |
| 检测引擎 | `0x080059E0`（三任务共用） |
| 点击阈值 | **140 按下 / 98 抬起**（2760 条报文实测） |
| 输出例程 | `0x08005E38`（唯一调用点 `0x08005B8C`） |
| **改动点** | `0x08005A90` ↔ file `0x1A54C`：`28 31`→`08 31`<br>`0x08005ABC` ↔ file `0x1A578`：`28 39`→`08 39` |

## ⚠️ 符号消歧（同一个串指不同东西）

| 符号 | 指什么 | 层 |
|---|---|---|
| `0x5A` / `0x5B` | **AW86927 的 I²C 从地址** | ① 器件地址 |
| `0x5B80` / `0x5B94` / `0x5B96` | **GT7868Q 的 16 位 RAM 地址**（阈值表） | ③ 芯片内部 |
| `5A A5` | **GT7868Q 主机报文魔数** | 主机 → GT7868Q |
| `0xC620/0xC621 = 5A/A5` | **EC 间接读签名**（**另一个项目**：开盖角度） | EC 协议 |
| `0x2C` | ① 主机总线上 GT7868Q 的地址 ② 片内 I²C1 上 TF100A 的地址 | ① / ③ |
| `1` | **不是 I²C 地址**（`_ADR` 模板遗留） | — |
| `0x1800` / `0x3800` | ① 片内参数区偏移 ② 主机报文类型 4 的写入目标 | ③ / 主机报文 |
