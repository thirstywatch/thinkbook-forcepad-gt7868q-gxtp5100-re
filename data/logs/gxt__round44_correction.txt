## A. ★ 纠错：可写窗口的真实边界

  0x1B8A4  movw r1,#0x9000 ; movt r1,#0x801   =>  r1 = 0x08019000
  0x1B8AC  add  r0, r1                          =>  addr += 0x08019000
  0x1B890  cmp.w r0,#0x7000  (在 add 之前，对原始 addr 判)
  => 可写窗口 = 0x08019000 + [0, 0x7000) = 0x08019000..0x08020000
  => 文件偏移 0x19000..0x20000，共 28 KB

  ⚠️ ROUND22 说这是'配置区'是**判据错误** ——
     0x1B874(写入封装)、0x1B780(擦页) 自身就在 0x1Bxxx，**落在窗口内**；
     窗口内熵 5.5~6.5、见 push{lr}(b580)/bx lr(4770)/b.n(e7ff) 指令序列、
     并且含 'TF100A_Test_FW' 与编译时间戳 —— 这是**代码段**。

## B. 窗口内关键锚点

  0x19ECC  'TF100A_Test_FW'   <- 钛方 TF100A 压力前端的固件标识
  0x19EEC  'Nov 28 2023'      <- 编译日期
  0x19F0C  '19:10:59'         <- 编译时间
  0x1B874  写入封装本体（在窗口内！）
  0x1B780  擦页函数（在窗口内！）
  0x1B9C8  写整页函数
  0x1BCA0  写 4 字节
