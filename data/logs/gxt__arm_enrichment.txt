================================================================================
0x1E000 中 ARM 特征的富集倍数检验
================================================================================

  判据：2 字节串在 N 字节区内的随机期望次数 = N / 65536
       富集倍数 = 实测次数 / 期望次数
       真代码里的功能序列 ：富集 10^2 以上
       偶然匹配          ：富集 10^0~10^1

  模式                                 实测       随机期望       富集倍数       判定
  ------------------------------------------------------------------------
  ARM: BX LR (函数返回)                   6      0.125       48.0        弱
  ARM: PUSH {R7,LR} (函数序言)           16      0.125      128.0      真信号
  ARM: NOP                            3      0.125       24.0        弱
  ARM: ADD SP,#32                     5      0.125       40.0        弱
  ARM: DMB ISH                        6      0.000  3145728.0      真信号
  ARM: PUSH.W 前缀                      0      0.125        0.0       噪声
  ARM: POP.W 前缀                       0      0.125        0.0       噪声
  ARM: MOV.W Rd,#imm                  0      0.125        0.0       噪声
  ARM: BL 前缀(thumb2)                  3      0.125       24.0        弱
  ARM: LDR.W literal                  0      0.125        0.0       噪声
  ARM: BLX R2                         0      0.125        0.0       噪声
  ARM: BLX R6                         0      0.125        0.0       噪声
  8051: RET + nop                    20      0.125      160.0      真信号
  8051: LCALL 0x0000                 12      0.125       96.0      真信号
  对照: 7f 7f                           0      0.125        0.0       噪声
  对照: ff ff                           0      0.125        0.0       噪声
  对照: 00 00                         109      0.125      872.0      真信号

【关键判断】函数序言/返回的配对率
  PUSH {R7,LR} = 16   POP.W 前缀 = 0   BX LR = 6
  真 ARM 代码应有 PUSH ≈ POP ≈ BX LR，且数量级在 (代码字节数/30) 量级
  此处 8 KB 若是 ARM 代码，应约 136 个函数

【决定性对照】同一批模式在'100%% 确定是 ARM Thumb 代码'上的计数
  0x00000（4096 B, 已确证 8051 真代码）:
    ARM: BX LR (函数返回)            实测   0  富集 0.0
    ARM: PUSH {R7,LR} (函数序言)     实测   0  富集 0.0
    ARM: NOP                     实测   0  富集 0.0
    ARM: ADD SP,#32              实测   0  富集 0.0
