## ★ 这份文件不是厂商密钥材料

它是**从固件自身恢复出来的**：加扰区存在大段零填充，`0 ⊕ K = K` 使 raw 中直接出现 K 的副本。

```
plaintext = 0x00  ⇒  ciphertext = 0x00 ^ K = K
```

**⇒ 不含厂商任何秘密，不含设备唯一信息，对不同机器/不同批次的同型号固件通用。**

任何人都能用 `method/03-obfuscation-crack.md` 的方法从自己取得的固件里重新导出它；本文件只是省去这一步。

## 这份文件也不是"数据表"

卡方 = 0.00 是 **keystream 的指纹**，不是数据表的指纹。
